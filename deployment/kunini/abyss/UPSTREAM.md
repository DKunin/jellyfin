# Abyss для Jellyfin

Файлы скопированы из `AumGupta/abyss-jellyfin` на commit
`2f809171ed7f3a34b5e78297608b5f2b63dd3f0f` (MIT). Для четырёх файлов без
финального перевода строки он добавлен. В `abyss.css` внешний
`material-icons-round.woff2` встроен как data URI из закреплённого пакета
`material-icons@1.13.12`, чтобы иконки не зависели от доступности jsDelivr.
`MATERIAL_ICONS_LICENSE` содержит Apache 2.0 из этого npm-пакета.
Контрольные суммы развёртываемых файлов находятся в `SHA256SUMS`.

Тема и Spotlight подключаются Nginx с локального same-origin пути
`/KuniniAbyss/`. Upstream-инсталлятор не запускается: он меняет настройки
пользователя, порядок секций и файлы внутри контейнера, что нарушает
воспроизводимость развёртывания.

При обновлении замените пять upstream-файлов, обновите commit и суммы,
измените cache-buster в обоих Nginx-конфигах и повторите полную проверку.
