# Журнал изменений

## 2026-10-29

- Поиск Jellyfin дополнен полкой `Not in your library`: TMDb-совпадения без локальных TMDb ID открываются во внутренней карточке с трейлером и ссылкой `MAGNET`.
- На внешнюю страницу фильма или сериала добавлена кнопка `TRAILER`: TMDb-видео открывается по запросу в privacy-enhanced YouTube-плеере без автозапуска, с внешней резервной ссылкой и очисткой iframe при закрытии.
- `View details` для внешней рекомендации переведён на same-origin страницу внутри Jellyfin с полными метаданными и основной кнопкой `MAGNET`; дублирующая кнопка `Search availability` удалена, а полка рекомендаций перенесена после локальной `More Like This`.
- Добавлен плагин `Kunini Discover`: веб-полка внешних рекомендаций TMDb на страницах фильмов и сериалов, фильтрация по локальным TMDb ID, same-origin proxy постеров, безопасные внешние ссылки и кнопка `MAGNET` с URL-кодированными названием и годом выпуска.
- Добавлен локальный интерактивный preview, использующий production JavaScript и CSS плагина без запуска Jellyfin.
- Сборка, read-only mount, Nginx-инъекция, проверки API/assets и инструкции отката расширены для второго плагина.
- Добавлен отдельный вход `media-app.kunini.ru` со стандартной авторизацией Jellyfin для мобильных и ТВ-клиентов; `media.kunini.ru` остаётся за Kunini Auth.
- Bridge разрешает direct-токены только для точного app-host от доверенного Docker gateway либо с перезаписываемым Nginx proxy-маркером, отклоняет подменённые identity-заголовки и покрыт регрессионными тестами.
- Добавлены отдельный TLS-сертификат, автоматическое продление, безопасный bootstrap/rollback и end-to-end проверки обоих входов.

## 2026-10-28

- Исправлена загрузка постеров сериалов: контейнер переведён на рабочие резолверы Quad9, а production-проверка теперь отклоняет loopback-ответы и недоступность API/изображений TMDb.
- Исправлен автовход в новом браузере: bridge продолжает отслеживать переход со стартового экрана Jellyfin на форму входа и покрыт регрессионным тестом.
- Добавлен совместимый с Jellyfin `12.4` bridge для бесшовного входа через `auth.kunini.ru`: изолированные пользователи, fail-closed заголовки, защита от повторного использования чужой браузерной сессии, read-only mount и автоматические проверки.
- Добавлено воспроизводимое развёртывание Jellyfin `v12.4` для `media.kunini.ru` с TLS, Kunini Auth, read-only медиатекой `/mnt/data/plex`, VA-API, автоматической настройкой библиотек и проверками production-состояния.
